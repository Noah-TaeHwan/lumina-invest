# 통제 주장 작성 지시(A-3: 주체 교체·표기 변형)

질문마다 아래 [문단 1~8]을 보고 주장 세 개를 만든다. 질문 머리줄에 배정된 "주체 교체 하위 유형"과 "표기 변형 유형"을 따른다.

1. true_text: 한 문단이 직접 말하는 사실 하나를 **다른 표현으로 의역**한 한 문장. 원문 문장을 그대로 옮기지 않는다. 문단에 없는 내용을 더하지 않는다. 회사·부문·제품·거래상대 이름 가운데 하나 이상이 들어가야 한다.
2. swap_text: true_text에서 **이름 하나만** 배정된 하위 유형의 다른 이름으로 바꾼 한 문장. 숫자·연도·서술어·조사 이외의 나머지는 그대로 둔다. 새 이름은 문단 8개 어디에도 없어야 한다(띄어쓰기·법인 표기를 바꿔도 없어야 한다).
   - 회사: 주어나 주제어인 회사 이름을 다른 실제 회사 이름으로.
   - 부문·사업: 사업부문·사업부·공장·설비 이름을 같은 회사에 없는 다른 부문 이름으로(예: "선재사업부문" → "단조사업부문").
   - 제품·브랜드: 제품·서비스·브랜드 이름을 다른 이름으로.
   - 거래상대·자회사: 고객·공급사·계약 상대·자회사·종속회사 이름을 다른 이름으로.
3. notation_text: true_text와 **같은 사실**을 이름 표기만 바꿔 쓴 한 문장. 나머지 글자는 그대로 둔다.
   - 법인 표기: 이름 앞뒤에 ㈜·(주)·주식회사를 붙이거나 떼거나 바꾼다(예: "한빛소재" → "㈜한빛소재", "한빛소재 주식회사").
   - 띄어쓰기: 이름 안의 띄어쓰기만 바꾼다(예: "고려제강" → "고려 제강", "단조사업 부문" → "단조사업부문").
   - 영문·약칭: 문단 8개에 **그대로 나오는** 영문 이름이나 약칭으로 바꾼다(예: 문단에 "에프엔씨엔터테인먼트(이하 'FNC')"가 있으면 "FNC"). 문단에 없는 약칭을 지어내지 않는다. 쓸 수 있는 영문·약칭이 없으면 notation_text를 null로 둔다(다른 유형으로 바꾸지 않는다). 이 경우에만 null을 쓸 수 있다.
- 이름을 바꾸기 어려운 문단(이름이 하나도 없는 사실뿐)이면 이름이 있는 다른 사실을 고른다.
- 출력은 "출력 파일" 경로에 질문마다 JSONL 한 줄로 쓴다:
  {"qid": "<qid>", "true_text": "...", "swap_text": "...", "swap_subtype": "<배정 하위 유형>", "notation_text": "...", "notation_type": "<배정 표기 유형>", "source_passage": <번호>}
- 파일 외의 곳을 수정하지 않는다.
