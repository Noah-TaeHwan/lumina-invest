# 근거 판정 엔진 Stage 1 리포트 — 홀드아웃 판정력 비교

- 날짜: 2026-10-02
- 설계: [spec](../superpowers/specs/2026-10-02-evidence-assistant-design.md) 3·5·6·7절, [계획](../superpowers/plans/2026-10-02-evidence-stage1.md)
- 사전등록: [`lab/evidence/prereg.json`](../../lab/evidence/prereg.json)(`stage1` 블록), 동결: [`lab/evidence/prereg_holdout.json`](../../lab/evidence/prereg_holdout.json)(커밋 `ac67040`)
- 자동 집계: [`lab/evidence/results/stage1.json`](../../lab/evidence/results/stage1.json), [`stage1-tune.json`](../../lab/evidence/results/stage1-tune.json)

> **정답 라벨은 사람이 아니라 AI(Claude Opus, Codex)가 독립적으로 붙이고 조정한 "AI 참조 라벨"이다.** 아래 수치는 모두 AI 참조 라벨과의 일치 성능이다.

## 결론

**주결과: 우월성 미확인, 실용적으로 동등.** 홀드아웃 자연 주장 228건에서 SYS(JEV + 숫자 존재 확인)와 최고 기준선(어휘 겹침)의 AUC 차이는 −0.005였다(95% −0.041~+0.024). 구간 전체가 사전등록한 동등성 마진 ±0.05 안에 들어간다.

| 판정기 | 홀드아웃 자연 주장 AUC |
|---|---|
| SYS(JEV + 숫자 존재 확인) | 0.979 |
| JEV 단독 | 0.976 |
| **B\* 어휘 겹침(숫자 확인 포함)** | **0.984** |
| 임베딩 유사도 | 0.730 |
| 다국어 NLI(mDeBERTa xnli) | 0.563 |
| 로컬 LLM(llama3.2:1b) | 0.538 |

**해석:**
- **JEV는 쓸 만한 판정기다.** 한국어 공시 문장 지지 판정에서 다국어 NLI 모델과 로컬 LLM을 크게 앞섰다. 판정 실패는 0건이었다.
- **이 평가 데이터에서는 단순 어휘 겹침도 그만큼 잘했다.** 이유는 답변 생성기(1B 로컬 모델)가 문단 문장을 거의 그대로 옮겨 쓰기 때문으로 본다. 지지되는 주장은 문단과 낱말이 많이 겹치고, 근거 없는 주장은 덜 겹친다.
- 그래서 사전등록 질문("JEV를 붙인 SYS가 최고 기준선보다 낫다")에 대한 답은 **"이 조건에서는 낫다고 말할 수 없고, 사실상 같다"**다.

## 진단: 문장을 바꿔 쓰면 달라진다 (주결과 아님)

통제 주장은 의역한 참 문장과 변형 문장(숫자·기간·주체·부정·다른 기업)으로 만든 진단 세트다. 혼합 비율을 사람이 정했으므로 주결과로 쓰지 않는다.

| 판정기 | 통제 주장 AUC (226건) | 의역 대 주체 교체 AUC (135건) |
|---|---|---|
| SYS | 0.980 | 0.970 |
| JEV 단독 | **0.994** | **0.998** |
| 어휘 겹침 | 0.818 | 0.639 |
| 임베딩 | 0.624 | — |
| NLI | 0.639 | — |
| 로컬 LLM | 0.509 | — |

- 문장을 다른 말로 바꿔 쓴 참 문장과 주체만 바꾼 거짓 문장을 가를 때, 어휘 겹침은 무작위에 가까웠다(0.639). JEV는 거의 완벽했다(0.998).
- 실제 서비스의 답변 생성기(더 큰 모델)는 문단을 옮겨 쓰기보다 바꿔 쓴다. 이 진단은 그런 조건에서 JEV의 이점이 커질 수 있음을 시사한다. 다만 사전등록한 결론이 아니며, 생성기를 바꾼 새 평가로 확인해야 한다.

## 운영점과 보조 지표 (τ_s 0.50, τ_c 0.35)

- **지지됨(✅) 판정:**
  - 정밀도 0.807, 재현율 1.000, 커버리지 0.522
  - 반박 오탐률 0.014
  - 사전등록 규칙대로 조정 세트에서 정밀도 0.90을 맞추는 가장 작은 τ_s(0.50)를 골랐다. 홀드아웃 정밀도는 0.81로 목표에 못 미쳤다.
- **숫자 없는 주장(97건):** SYS 0.968, 어휘 겹침 0.981
- **3분류 macro-F1:** 0.752
- **군집별 Δ 부호:** 양 2, 음 3, 계산 불가 1(12군집 중 한 클래스만 있는 군집 제외). 군집마다 결과가 엇갈려 일관된 우열이 없다.
- **통제 주장 변형 유형별 SYS 정확도:** 의역 0.97, 숫자 변경 1.00, 기간 1.00, 부정 1.00, 다른 기업 1.00, **주체 교체 0.45**
  - 주체 교체 문장은 JEV 확률로는 잘 갈리지만(위 표), 지지 확률이 0.5 근처에 걸려 τ_s 0.50에서 "지지됨"으로 넘어가는 경우가 많았다.
- **민감도(갈린 라벨 7건, 제외율 3.0%):**
  - Opus 라벨로 넣었을 때 Δ = −0.002(−0.038~+0.025)
  - Codex 라벨로 넣었을 때 Δ = −0.004(−0.040~+0.023)
  - 결론은 바뀌지 않는다.

## 제품 설계 시사점 (A-2)

1. **✅ 임계값을 0.5보다 높인다.** Stage 0의 반복 일관성 경계선 사례와 홀드아웃 정밀도 0.81, 주체 교체 오판정 모두 0.5 근처에서 생겼다. A-2에서 정밀도 우선으로 다시 정하되, 이 평가와 분리된 새 데이터로 정한다.
2. **어휘 겹침은 싸고 강한 1차 필터다.** "규칙 먼저, JEV는 잔여만"(Vault 교훈)과 같은 방향이다. 겹침이 아주 높거나 아주 낮은 주장은 규칙으로 정하고, 애매한 구간과 의역 문장만 JEV에 묻는 계층형 설계가 비용과 성능 모두에 유리할 수 있다. 이 가설은 아직 검증하지 않았다.
3. **생성기가 바뀌면 다시 잰다.** 서비스 생성기는 바꿔 쓰기가 많을 것이므로, A-2 이후 실제 생성기 답변으로 같은 비교를 다시 한다.

## 한계

- 정답이 AI 참조 라벨이다. 숫자 주장 50건과 통제 불일치 2건을 원문과 대조한 표본 감사에서 이진 판정이 바뀌는 오류는 없었다. 사람 감사는 하지 않았다.
- 판정은 검색된 문단 8개 기준이다. 검색 품질은 중간이다(`nomic-embed-text`).
- 1B 생성기의 문체가 어휘 겹침 기준선에 유리하게 작용했을 수 있다(위 해석).
- 홀드아웃은 20개사 12군집이다. 실제 Δ가 ±0.08 안이면 검출하기 어려운 크기다(사전등록 MDE 0.083).
- 홀드아웃 1개사(01368637)는 DART 등록명과 보고서 본문의 회사명이 달랐다(사명 변경 추정). JEV state의 회사명은 DART 이름을 썼다.
- 숫자 존재 확인은 리뷰 지적을 반영해 개선했다. 그래도 날짜 형식이나 열 머리글 단위 같은 공시 표기 변형을 전부 다루지는 못한다.
