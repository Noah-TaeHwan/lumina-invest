# Stage 1 규칙 재선택 사전 분석

- 작성: 2026-10-01, Stage 0 세션 1 이후
- 범위: **개발 구간(2025-10-01~2026-04-30)만** 사용했다. 검증·홀드아웃 구간 가격은 보지 않았다. JEV는 호출하지 않았다.
- 방법: 1분봉 종가 진입·청산 근사, 포지션 1개, 왕복 비용 0.22%(taker 0.1% × 2 + 슬리피지 1bp × 2). 손절 2·ATR, 익절 3·ATR. 5분봉·15분봉은 1분봉을 묶어 만들었다.
- 재현: `lab/analysis/rule_options.py`, 원본 출력 `lab/analysis/rule_options.json`

## 해석

1. **봉 주기를 늘리면 구조 문제는 풀린다.** 1분봉에서는 익절폭 중앙값이 비용의 0.83배라 목표가에 닿아도 순손실이었다. 5분봉 이상에서는 2~4배가 된다.
2. **하지만 이 기간 Donchian 돌파에는 비용 전 우위가 없다.** 모든 변형에서 비용 전 거래당 평균이 −0.04%~+0.0002%로 0 근처다. 비용 0.22%를 넘어서는 수익을 기대할 근거가 없다.
3. 따라서 Stage 1에서 "JEV 게이트를 붙였더니 수익이 났다"는 결과가 나올 가능성은 낮다. 의미 있게 검증할 수 있는 것은 **판정력**이다. JEV의 실패 확률이 실제로 실패한 거래와 관련 있는지를, 차단율을 맞춘 무작위·결정론·로지스틱 대조군과 비교해 보는 것이다(spec의 H-predict).

## 추천

- **5분봉 N=48, 시간청산 24봉(2시간)으로 바꾼다.**
  - 익절폭/비용이 2.28배라, 익절(성공)과 손절(실패) 라벨이 실제 순손익과 같은 방향이 된다.
  - 개발 구간 후보 1,279건으로 사전등록 기준(300건 이상)을 넘는다.
  - 호출 수가 1분봉의 약 3분의 1이다.
- **주결과를 H-predict(판정력)로, H-profit(수익)은 보조 결과로 둔다.** 결과가 부정적이어도 같은 형식으로 공개한다는 spec 원칙은 그대로다.
- 바꾸려면 사전등록 v3이 필요하다(봉 주기, N, 시간청산, 질문 문구의 "1-minute"·"120-minute"). 질문 해시가 바뀌므로 Stage 0의 반복 일관성은 새 질문으로 소규모로 다시 잰다(약 50건 × 5회, 비용 약 $0.01). 지연·실패율은 같은 API·같은 입력 형식이라 그대로 참고한다.

## 대안

- **1분봉 유지:** 게이트 효과를 "손실 전략 차단"으로만 해석한다고 명시한다. 이긴 거래도 순손실이라 판정 라벨과 손익이 어긋나는 문제가 남는다.
- **15분봉:** 익절폭/비용은 가장 좋지만(4.04배), 후보가 793건으로 줄고 비용 전 성과는 가장 나쁘다.

## 결정 필요 (노아)

- 주결과를 판정력(H-predict)으로 둘지
