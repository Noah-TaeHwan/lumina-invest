## 홀드아웃 비교 (일 단위 블록 부트스트랩 95% 구간)

- 아직 동결 전이거나 홀드아웃 응답이 없다. 동결 전에는 홀드아웃·공개 이후 구간의 결과를 계산하지 않는다.
